# Bundled runtime notices

This is a local Windows x64 engineering artifact. It includes third-party components under their own licenses. This inventory does not grant blanket redistribution rights or certify compliance for a public release. The stock XM5 UI resources retain the separate restrictions in `xm5lib/ui/assets/NOTICE.md`.

Python 3.14.10 is the official CPython Windows x64 embeddable package from python.org. `vendor/python/LICENSE.txt` is retained. Its SHA256 comes from the official release manifest. This tested maintenance version preserves the cp314 ABI while avoiding dependence on the older installed development runtime. No Python installer, registry setup, user site or installed Python is used at application runtime.

PySide6-Essentials and shiboken6 6.12.0 are unchanged official Qt wheels from PyPI. Their distribution metadata and original license files remain under `vendor/python/Lib/site-packages`; supplementary upstream LGPLv3/GPLv2/GPLv3 and other license texts are in `vendor/notices/Qt-LICENSES`. These dynamically loaded DLLs can be replaced by a compatible user-built version. Qt for Python source: https://code.qt.io/cgit/pyside/pyside-setup.git/tag/?h=v6.12.0 . Qt source modules are available from https://download.qt.io/official_releases/qt/6.12/6.12.0/submodules/ . The publisher's licensing/third-party attribution page is preserved as `Qt-for-Python-licenses.html`.

The official PySide6 wheels also contain Microsoft Visual C++ runtime DLLs. Three unchanged copies are placed beside mpv because Windows child executables do not search the Python interpreter directory. This avoids requiring a global runtime installation. These Microsoft files retain their own terms; they are not relicensed under the application's or Qt's license. Microsoft's redistribution guidance is preserved in `Microsoft-redistributing-visual-cpp-files.html` and is available at https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files . No Microsoft installer is executed.

Its immutable asset name and SHA256 are recorded in `portable-lock.json`. The archive also contains the required Vulkan loader; `vulkan-1.dll` is kept beside mpv. This is a development build, not an official stable release or hardware validation. The mpv source copyright and GPL text are retained here. The CI script, preserved here, enables GPL and FFmpeg GPL components; treat the combined build as GPLv3-or-later. Source and build recipe: https://github.com/mpv-player/mpv/tree/902818753 . Vulkan loader source: https://github.com/KhronosGroup/Vulkan-Loader ; Vulkan header source: https://github.com/KhronosGroup/Vulkan-Headers . Their upstream licenses are retained. The upstream CI follows some dependency branches; a complete exact reconstruction of every linked mpv dependency is not established by this artifact.

The release-specific GitHub asset URL and SHA256 are recorded in `portable-lock.json`. `vendor/ffmpeg` retains the builder's GPLv3 license, README, exact configuration, dependency versions and documentation. No dependency is copied from a user profile. The source program remains editable and is not frozen into the media binaries.
